# Portfolio Hồ Công Minh · INF2501

Website Portfolio tĩnh (HTML/CSS/JavaScript thuần) giới thiệu bản thân và 06 bài tập của học phần "Nhập môn Công nghệ số và ứng dụng trí tuệ nhân tạo". Được xuất bản trên Netlify.

## Chạy trên máy
Không cần cài đặt hay build: mở `index.html` bằng trình duyệt. Hoặc chạy `python3 -m http.server`, rồi vào http://localhost:8000.

## Cấu trúc
- `index.html` (Giới thiệu), `projects.html`, `bai1.html` … `bai6.html`, `conclusion.html`, `404.html`
- `css/style.css`: toàn bộ giao diện
- `js/main.js`: menu, chân trang, tô sáng placeholder
- `images/`, `files/`: ảnh và tệp đính kèm

Xem PLAN.md: điền nội dung các bài, hướng dẫn triển khai, tính năng điểm thưởng, checklist cuối.
